# Happy Birthday Mallesh 🎉

GitHub Pages-ready static website.

## Run locally
Open `index.html` with Live Server in VS Code.

## GitHub Pages
Upload the **contents of this folder** to the root of your GitHub repository (not the enclosing folder):

- `index.html`
- `style.css`
- `README.md`
- `assets/`

Then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

Keep the `assets` folder and all files inside it together. The site uses relative paths such as `assets/mallesh-memory-1.jpg` and `assets/birthday-music.mp3`, which work on GitHub Pages project URLs.

After deployment, hard-refresh the page if an older version is cached.
